# SEO-план по этапам 1–5

Частотности я не придумываю: ниже запросы для проверки в Вордстате и Search Console.

## Этап 1. Стратегия и семантика
Основной интент: навигационно-справочный («телефон, адрес, график»). Конкуренты: 2ГИС, Яндекс Карты, Zoon, сайты ЦРБ. Наше преимущество: все пять районов и сравнение в одном месте, вручную проверенные данные.

## Этап 2. Структура
```
/ → /rayony/ → /rayony/<район>/
  → /medicina/ → /medicina/<район>/ → /medicina/<район>/<организация>/
               → /medicina/crb/, /medicina/stomatologiya/, /medicina/laboratorii/
  → /partnery/ ; /veterinariya/, /yuridicheskie-uslugi/, /pansionaty/, /intellekt-klub/ (noindex)
  → /o-proekte/, /kontakty/, /avtor/, юридические страницы
```
Глубина не больше 4. Перелинковка: карточка → список района → хаб; карточка → «другие этого типа в районе»; главная → ротация ссылок (10 на секцию).

**Места партнёров:**
- бегущая строка: главная, `/rayony/`, `/medicina/` (ведёт на внутренние страницы направлений);
- карточки «Услуги партнёров»: главная и страницы районов;
- «Справка для семьи» (пансионаты): карточки больниц, поликлиник, амбулаторий, ФАПов и `/medicina/`;
- внешние ссылки с `rel="sponsored noopener"` только на `/partnery/` и четырёх страницах направлений: так не получится сетка сквозных ссылок (check.mjs это проверяет);
- остальные сайты автора: названия без ссылок.

## Этап 3. Шаблоны
Карточка организации: title «Название, район: телефон, адрес» (≤60), description из адреса, телефона и графика (≤160), блок ответа, таблица-паспорт, примечание, предупреждение об уточнении, ссылки на соседние. Разметка: Hospital, Dentist или MedicalOrganization только с теми полями, что есть в данных; BreadcrumbList, WebPage, Person.

## Этап 4. Технический каркас
Статический HTML, весь контент без JS; sitemap.xml с разбивкой, robots.txt, canonical, 404, CNAME, HTTPS на GitHub Pages; Метрика после согласия; llms.txt, ai-guide.txt, ai-catalog.json, webmcp.js. Чек-лист запуска: добавить сайт в Вебмастер и Search Console, отправить sitemap, проверить мобильную версию в PageSpeed, проверить разметку в валидаторе.

## Этап 5. Контент (волна 1 готова)
Собрано из Health.txt: 60 карточек, 5 страниц районов, 5 списков медицины по районам, 3 сводные страницы, партнёры, О проекте, Контакты, Автор, 3 юридические. Следующая волна требует ваших фактов: статьи «Как записаться к врачу в ЦРБ <район>», «Куда звонить в экстренной ситуации», разбор по каждому ФАПу. Пишите по формату `content/stati/_шаблон.md`.
