# Что нужно от владельца и что проверить перед запуском

## Данные
1. **Другие направления.** Есть данные только по медицине (60 организаций). Для «компаса по всем направлениям» нужны такие же собранные файлы: администрации и МФЦ, школы и детсады, транспорт и расписания, магазины и аптеки, банки, суды, культура, ветеринария по районам. Формат тот же, что в Health.txt: заголовок района, «## N. Название», строки Адрес / Телефон / Электронная почта / Сайт / График / Примечание. Новый раздел добавляется копированием `parse-health.mjs`.
2. **Пробелы в Health.txt.** Нет телефона: «ООО «Стоматология»» (Дуванский район). Нет графика у большинства амбулаторий Салаватского района, у ряда стоматологий и ФАПов. Страницы показывают «не указан», пока данных нет.
3. **Даты.** Салаватский и Дуванский районы актуальны на 16.11.2026, остальные на 21.11.2026. Дата показана на каждой странице организации.

## Юридическое
4. **Политика, Согласие, Условия** составлены по вашей политике Судпомощника, адаптированы под сайт без услуг и форм. По вашему же правилу тексты нужно показать юристу до запуска.
5. **Реклама.** Партнёрские блоки помечены как проекты автора. Если за размещение платят третьи лица, по закону о рекламе нужна пометка «Реклама» и маркировка (токен erid). Уточните у юриста для вашей схемы.
6. **Страницы направлений** (`/veterinariya/`, `/yuridicheskie-uslugi/`, `/pansionaty/`, `/intellekt-klub/`) пока `noindex`: текста о партнёрах мало, это риск «тонких» страниц. Чтобы открыть для поиска, добавьте реальные факты и уберите `noindex: true` в `content/pages.mjs`.

## Техническое
7. **Метрика.** Счётчик 114506332 подключён только после согласия. Цели для настройки: `call_org`, `partner_zoo`, `partner_sud`, `partner_pansionat`, `partner_club`, `ticker_*`, `mail_ads`, `call_ads`, `call_sud`.
8. **Вебмастер и Search Console.** После публикации добавьте sitemap.xml, проверьте индексацию 83 страниц.
9. **Бегущая строка** стоит на главной, `/rayony/` и `/medicina/`: есть кнопка «Пауза», остановка при наведении и отключение при настройке системы «уменьшить движение».
